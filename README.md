# Image Processing with Streamlit

This project is a Streamlit-based web application for performing basic image processing tasks, such as adding noise, removing noise, flipping, and rotating images. It uses OpenCV and NumPy for image manipulation.

## Features

- **Capture Image**: Use your webcam to capture an image directly in the app.
- **Add Noise**: Apply different types of noise to the image:
  - Gaussian Noise
  - Salt & Pepper Noise
  - Poisson Noise
  - Speckle Noise
- **Remove Noise**: Use various filters to remove noise:
  - Gaussian Blur
  - Median Blur
  - Normal Blur
- **Flip Image**: Flip the image horizontally.
- **Rotate Image**: Rotate the image by 90°, 180°, or 270°.
